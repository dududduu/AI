# 인계 게이트

## 목적과 상태

앞 단계의 오류가 다음 담당의 작업 전체로 번지는 것을 막는다. 팀장이 실제 파일과 근거를 읽고 판정하며 보낸 담당의 자기평가만으로 통과시키지 않는다.

- `통과`: 근거가 확인되고 다음 작업에 사용할 수 있음
- `경고`: 진행은 가능하지만 보완 조건이 있음
- `차단`: 다음 작업을 시작하면 결과가 왜곡될 위험이 큼
- `미평가`: 필요한 파일·정보·권한이 없어 판단하지 못함

필수 항목에 `차단` 또는 `미평가`가 있으면 `수정 필요`다. 경고만 있으면 `조건부 준비`, 모두 통과하면 `준비`다.

## G1 연구계획서에서 문헌검색으로

| 필수 항목 | 통과 조건 |
|---|---|
| 버전 | 계획서·가정·검수 파일의 명세 버전 일치 |
| 연구 질문 | 일반적으로 1~3개이며 목적과 연결됨 |
| 설계 | 질문별 자료·수집·분석·판단 기준 연결 |
| 품질 점수 | 20점 중 16점 이상이고 0점 없음 |
| 윤리 | 중대한 윤리·안전 차단 요소 없음 |
| 근거 | 확인하지 않은 인용이나 조작된 서지 없음 |

미통과 시 문제 파일·위치, 영향과 수정 조건을 연구계획서 담당에게 반환한다.

## G2 문헌검색에서 통합으로

| 필수 항목 | 통과 조건 |
|---|---|
| 버전 | 검색 결과가 최신 계획서 명세를 사용함 |
| 검색 기록 | DB, 검색일, 검색식과 포함·제외 기준 존재 |
| 질문 대응 | 각 질문에 문헌 연결 또는 검색 공백 명시 |
| 서지 검증 | 채택 문헌의 저자·연도·제목·발행처 확인 |
| 식별자 | DOI 또는 실제 URL과 메타데이터 일치 |
| 품질 점수 | 16점 중 13점 이상이고 0점 없음 |
| 정직성 | 검증 실패와 접근 제한을 기록함 |

미통과 시 문제 문헌 ID, 실패한 확인 항목과 재검색 조건을 문헌검색 담당에게 반환한다.

## G3 최종 통합

| 필수 항목 | 통과 조건 |
|---|---|
| 파일 존재 | 요청 범위의 실제 산출물이 모두 존재함 |
| 버전 일치 | 모든 산출물이 같은 최신 명세를 사용함 |
| 내용 일치 | 문헌 관련성이 연구 질문과 충돌하지 않음 |
| 변경 영향 | 검색으로 전제가 바뀌면 계획서를 재검수함 |
| 사용자 결정 | 미확정 조건과 사람이 할 일을 구분함 |
| 완료 표현 | 작성·검색·검수와 실제 연구 수행을 구분함 |

## 반복과 중단

- 각 담당의 최초 검수를 포함해 같은 명세 버전에서 최대 3회까지 수정한다.
- 핵심 명세가 바뀌면 새 버전으로 기록하고 영향받는 게이트부터 다시 판정한다.
- 3회 후에도 미통과이면 자동 반복을 멈추고 미달 항목, 원인, 필요한 정보와 선택지를 사용자에게 보고한다.
- 게이트 기록은 덮어쓰지 않고 해당 검수 파일에 회차별로 남긴다.
