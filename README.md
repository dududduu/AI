# 범용 연구 계획서 작성 에이전트

어떤 분야의 연구 아이디어든 연구 가능한 질문과 실행 가능한 계획서로 발전시키는 단일 Codex 에이전트 프로젝트입니다. 인문학, 사회과학, 교육, 자연과학, 공학, 정보·컴퓨터, 보건·의학, 예술·디자인 및 학제 간 연구를 지원합니다.

## 사용 방법

1. 이 저장소를 내려받거나 복제합니다.
2. 저장소 폴더를 Codex 프로젝트로 엽니다.
3. 별도의 프롬프트 파일을 지정하지 않고 연구 아이디어를 자연어로 입력합니다.
4. 에이전트는 연구 범위와 방법을 정하고 필요한 경우 한 번에 1~3개의 핵심 질문을 합니다.
5. 연구별 폴더에 계획서·가정 기록·검수 기록을 저장합니다.
6. G1 접수부터 G6 전달까지 한 에이전트가 단계 상태를 기록하며 진행합니다.
7. 0~2점 품질 루브릭으로 최대 3회 검수한 뒤 결과를 보고합니다.

## 산출물 구조

```text
projects/
└─ <연구명-케밥표기>/
   ├─ proposal.md       # 연구 계획서
   ├─ assumptions.md    # 사용자 답변, 가정, 미확정 사항
   └─ review.md         # 회차별 점수, 근거, 수정 기록
```

총점 16점 미만이거나 0점 항목이 있으면 계획서를 수정하고 다시 채점합니다. 최초 채점을 포함해 최대 3회까지만 진행하며, 이후에도 미달이면 원인과 필요한 정보를 사용자에게 보고하고 추가 진행 승인을 받습니다.

## 단일 에이전트 작업 흐름

```text
G1 접수 → G2 범위 → G3 설계 → G4 초안 → G5 검수 → G6 전달
```

각 단계는 `준비`, `조건부 준비`, `수정 필요`로 판정합니다. 이 게이트는 여러 에이전트가 일을 주고받는 구조가 아니라, 한 에이전트가 연구 명세와 산출물의 일관성을 확인하는 내부 절차입니다. 연구 질문·대상·핵심 자료·연구 유형·제출 요건이 바뀌면 명세 버전을 올리고 영향받는 단계를 다시 확인합니다.

연구 질문별로 필요한 자료, 수집 방법, 분석 방법, 판단 기준과 윤리 조건을 추적표로 연결합니다. 출처는 `원문 확인`, `초록·서지 확인`, `미확인`으로 구분하며, 확인하지 못한 자료는 참고문헌으로 만들지 않습니다.

## 요청 예시

- 조선 후기 여성의 한글 편지가 가족 관계를 어떻게 보여주는지 연구하고 싶어.
- 도시 공원의 녹지 비율과 여름철 지표면 온도의 관계를 연구 계획서로 작성해줘.
- 새로운 재활 보조기구를 개발하고 사용성과 안전성을 평가하는 연구를 설계해줘.
- 생성형 AI가 중학생의 프로그래밍 학습에 미치는 영향을 연구하고 싶어.

## 프로젝트 구성

- `AGENTS.md`: 역할과 범위, 연구 유형 선택, 분야별 고려사항, 전체 작업 절차와 품질 루프
- `projects/`: 에이전트가 주제별로 생성하는 연구 기록
- `examples/lesson-research-proposal.md`: 교육 분야 계획서 작성 사례
- `.gitignore`: API 키, 개인정보, 비공개 데이터, 논문 원문과 임시 파일 제외 규칙

## 에이전트의 범위

에이전트는 연구 계획서의 설계·작성·검수를 담당합니다. 실제 연구윤리 승인, 기관 허가, 참여자 모집·동의, 실험·자료 수집 또는 전문위원회의 최종 판단을 대신하지 않습니다. 권한이나 전문성이 필요한 결정은 필요한 자료와 선택지를 정리해 사용자 또는 담당 기관에 넘깁니다.

이 저장소는 하나의 에이전트만 사용합니다. 단계 표시는 품질 관리용이며 별도 하위 에이전트, 오케스트레이터 또는 자동 핸드오프를 만들지 않습니다. 계획서 파일이 생성되었다는 사실만으로 연구가 수행되었거나 승인·효과 검증이 끝난 것은 아닙니다.

## 개인정보와 연구 자료

공개 저장소에 API 키, 인증정보, 개인정보, 인터뷰 원문, 비공개 데이터와 저작권이 있는 논문 원문을 올리지 마세요. `.gitignore`는 일반적인 민감 파일을 제외하지만 모든 내용을 자동으로 판별하지는 못합니다. 커밋하기 전에 `git status`와 실제 내용을 확인하세요.

`projects/`의 계획서와 기록에는 공개 전 아이디어가 포함될 수 있습니다. 공개 저장소에 올리기 전 세 파일을 검토하고 민감한 정보는 제거해야 합니다.
