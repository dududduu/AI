# 범용 연구 계획서 작성 에이전트

어떤 분야의 연구 아이디어든 연구 가능한 질문과 실행 가능한 계획서로 발전시키는 Codex 프로젝트입니다. 인문학, 사회과학, 교육, 자연과학, 공학, 정보·컴퓨터, 보건·의학, 예술·디자인 및 학제 간 연구를 지원합니다.

## 사용 방법

1. 이 저장소를 내려받거나 복제합니다.
2. 저장소 폴더를 Codex 프로젝트로 엽니다.
3. 별도의 프롬프트 파일을 지정하지 않고 연구 아이디어를 자연어로 입력합니다.
4. Codex는 `AGENTS.md`를 자동으로 읽고 분야와 연구 유형을 판별합니다.
5. 필요한 조건을 질문하거나 합리적인 가정을 명시한 뒤 연구 계획서를 작성합니다.

기본 산출물 파일명은 `research-proposal.md`입니다. 여러 연구를 진행할 때는 주제별 영문 소문자 케밥 표기 파일명을 사용합니다.

## 요청 예시

- 조선 후기 여성의 한글 편지가 가족 관계를 어떻게 보여주는지 연구하고 싶어.
- 도시 공원의 녹지 비율과 여름철 지표면 온도의 관계를 연구 계획서로 작성해줘.
- 새로운 재활 보조기구를 개발하고 사용성과 안전성을 평가하는 연구를 설계해줘.
- 생성형 AI가 중학생의 프로그래밍 학습에 미치는 영향을 연구하고 싶어.

## 프로젝트 구성

- `AGENTS.md`: 에이전트의 역할, 연구 유형 판별, 분야별 기준, 계획서 구조와 검토 기준
- `examples/lesson-research-proposal.md`: 교육 분야 연구 계획서 작성 사례
- `.gitignore`: API 키, 개인정보가 포함될 수 있는 연구 자료, 논문 원문과 로컬 산출물 제외 규칙

## 개인정보와 연구 자료

공개 저장소에 API 키, 인증정보, 개인정보, 인터뷰 원문, 비공개 데이터와 저작권이 있는 논문 원문을 올리지 마세요. `.gitignore`가 일반적인 민감 파일을 제외하지만 모든 파일을 자동으로 판별하지는 못합니다. 새로운 파일을 커밋하기 전에 `git status`와 실제 내용을 확인하세요.

생성된 계획서에는 아직 공개하지 않은 연구 아이디어나 개인정보가 포함될 수 있으므로 기본 `research-proposal.md`는 Git에서 제외됩니다. 공개할 계획서는 내용을 검토한 후 파일명을 변경하거나 `.gitignore` 규칙을 조정해 별도로 추가하세요.

## 적용 범위

에이전트는 연구 유형에 따라 문헌·이론, 역사, 질적, 조사·상관, 실험·준실험, 사례, 설계·개발, 자연과학 실험, 계산·데이터, 예술·실기 또는 혼합방법 연구 절차를 선택합니다. `examples`의 교육 연구 사례는 사용 예시이며 에이전트의 적용 분야를 제한하지 않습니다.
